# Legal — Política de Privacidad

## Datos recogidos
- **Datos de cuenta**: nombre, email, teléfono, rol, tenant.
- **Datos de conversaciones**: mensajes, archivos adjuntos, metadatos (fecha, canal).
- **Datos de contacto**: nombres, teléfonos, emails de los clientes finales del tenant.
- **Registros IA**: interacciones, correcciones, confidence scores, indistinguishability.

## Uso de datos
- Solo para operar el servicio: enrutar mensajes, entrenar el agente IA del tenant,
  generar reportes, cumplir compliance.
- No se usan datos de un tenant para entrenar el agente de otro tenant sin
  anonimización explícita (`agent_global_knowledge`).

## Derechos del usuario (CCPA / LFPDPPP / Ley 1581)
- Acceso: exportar todos sus datos en JSON.
- Rectificación: corregir datos de contacto.
- Cancelación: eliminar cuenta y datos asociados (30 días de gracia).
- Oposición: no uso de datos para mejoras del producto.
